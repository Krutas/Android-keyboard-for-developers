Keyboard controls

Terminal mode is always available. 📋 opens clipboard history; ⭐ lets you save and insert reusable snippets. Lithuanian letters appear above numbers 1–9 (hold a number to type its letter). Hold comma or period for punctuation alternatives. Hold Space to choose LT / EN. The top-right LT 🎙 button opens the voice dictation window (hold to change language); the bottom 😀 key opens emojis. Test the keyboard in the white document. 📎 selects any file and inserts a temporary local link.

Tap the left or right edge of Space to insert < or >; tap the center for a space. Tap the virtual keys to type in the white document. In Configure, tap two keys to swap positions. Use + Combo to add keyboard shortcuts.

Editing mode

Tap a key, then tap its new location to swap them. Works across rows. Tap the selected key again to cancel. You can also drag keys on desktop.

Export

Keyboard profiles are stored in this browser. Export JSON for a future Android build.
